      前後のダイヤ

      位置情報を許可するには

      1. iPhone の「設定」→「プライバシーとセキュリティ」→「位置情報サービス」をオンにする
      2. 同じ画面を下にスクロールして「Safari の Web サイト」→「次回確認」か「このAppの使用中」を選び、「正確な位置情報」もオンにする
      3. Safari でこのページを開き、アドレスバーの「ぁあ」（または「…」）→「Web サイトの設定」→「位置情報」を「確認」か「許可」にする
      4. ページを再読み込みして、もう一度 📍 を押す

      ホーム画面のアイコンから開いている場合は、上の 1・2 を確認してからアプリを開き直してください。それでもだめなときは、アイコンを削除して Safari から「ホーム画面に追加」し直すと許可の確認が出ます。
